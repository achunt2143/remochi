# Remochi v0.6.0

Remochi 0.6.0 follows the Mochi / webOS design guide more closely. Panes are lighter, `RepanelStack` can peek at the previous and next panel, and the type, colour and motion rules are written into tokens. It also ships the nubbins and `Spinner` drawn in code, which 0.5.1 never released.

## Highlights

- **A lighter pane.** A 1px left edge, no stack shadow by default, and a full-bleed base pane.
- **Peeks and width classes.** `RepanelStack` `upcoming` and `keepPast` show slivers of the next and previous panel; `useWidthClass`, `SCREEN_NARROW` and `SCREEN_WIDE` are new.
- **Waterdrop as an accent.** New `Avatar`, a waterdrop `Dialog`, and `FloatingPanel` `shape="drop"`.
- **`Label` and `Header size="display"`** complete the type ladder.
- **Colour and contrast.** Contrast floors, a single focus ring, greyscale cues for selection, and a darker light `--color-primary`.
- **Motion modes.** Full, Reduced and Off, plus `contrast` and `transparency` modes on `ThemeWrapper`.
- **Drawn nubbins, divider caps and `Spinner`.** No PNG or GIF sprites in `src`; the `Spinner` is an SVG.
- **Fixes.** `PopupPanel` action types, `Item` ARIA, keyboard focus rings, a `NaN` popup position, portal fonts, `NubbinDivider` joints and the `Toggle` On position.
- **`npm run check:tokens`** guards bare hex colours and contrast floors.

## Upgrading

This release has visible and behavior changes. Read [Upgrading from 0.5.x](../../RELEASE_NOTES.md#upgrading-from-05x) in `RELEASE_NOTES.md` before bumping. It lists the tokens that bring the 0.5 look back.

## Install

```
npm install remochi@0.6.0
```

The Duyo Remochi pack 1.2.0 supports this release.
